# 三条知识链路验收素材

本目录为三条知识链路准备最小运行说明素材与验收口径，内容不包含密钥或外部环境依赖。

- `minimal-source.md`：通用无敏感 Markdown 样本。
- `nano-source.md`：Nano Brain 链路的唯一事实样本。
- `traditional-source.md`：Traditional RAG 链路的唯一事实样本。
- `graph-source.md`：GraphRAG 链路的唯一事实样本。
- `private-source.md`：用户私有场景的跨用户隔离验收样本。
- `acceptance-checks.md`：配置有效模型密钥后的人工验收清单。

健康检查只代表服务就绪；三条链路的检索结果仍需按本清单单独确认。
